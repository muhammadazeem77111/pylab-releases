# PyLab — Official Downloads

**PyLab** is a beginner-friendly Android app for students to write, run, and practice **Python** on their phone — no laptop needed.

This page is the **official download page** for PyLab. The app source code is maintained in a private repository; only the ready-to-install app (APK) is published here.

## 📥 Download the Latest Version

➡️ **Go to the [Releases page](https://github.com/muhammadazeem77111/pylab-releases/releases/latest)** and download the `PyLab-v1.2.apk` file.

**Latest version:** 1.2 — input() fix, plus new STOP and CLEAR buttons in the editor.

## 📱 How to Install

1. Open the **Releases** link above and download the APK file.
2. Tap the downloaded file to install it.
3. If your phone asks, allow **"Install unknown apps"** for your browser/Files app — this permission is only used to install PyLab.
4. Open **PyLab** and start coding.

> If PyLab is already installed, installing the new APK will update it — your saved programs stay safe.

## 🐍 What You Can Do in PyLab

- Write Python code in a proper editor with syntax highlighting
- Run programs on the phone itself — including `input()`
- Learn from built-in topics and ready-made examples
- Practice exercises and save your own programs

## ℹ️ Notes for Students

- Only download PyLab from this page or Google Play. Copies from anywhere else are not official.
